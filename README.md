
# Local Llama-Powered Conversational AI Assistant 🤖

## About the Project
A conversational AI assistant powered by a locally
running Llama 3.2 language model.

## Technologies Used
- Python
- Streamlit
- LangChain
- Ollama
- Llama 3.2
- Speech_to_text
- Asyncio

## Main Features
- Interactive chat interface
- Conversation history
- Text-to-Speech functionality
- Speech-to-Prompt functionality
- Local LLM integration

- ai_assistant - Main application
